Rādās tikai savi (demo-user-1) ieradumi. Testēts uz Android.

Projekta izstrādes laikā tika izmantots:

- MI rīks Gemini šādām vajadzībām:

1) Uzzināt, kā ir pieņemts nosaukt projektus .NET risinājumā.
2) Uzlabot koda kvalitāti atsevišķos failos (norādīts ar komentāriem šajos failos).
3) Uzzināt, kā strādā DTO, kāpēc tie ir vajadzīgi un kā tos implementē C#.
4) Uzzināt, kā padod JSON serializātoram divus sarakstus uzreiz, un saģenerēt atbilstošo kodu.
5) Saprast, ka JSON serializācijai vajadzīgs konstruktors, kur visu parametru tipi un nosaukumi sakrīt ar publisku īpašību tipiem un nosaukumiem klasē.
6) Uzzināt, kā viewmodeļos iegūt lietotāja ID.
7) Uzzināt, kā izveidot vienu lapu ar trīs cilnēm, un saģenerēt atbilstošo kodu.
8) Uzzināt, kā izvadīt lietotājam uznirstošo logu ar ievadi, un saģenerēt atbilstošo kodu.
9) Uzzināt, kā salidzīnāt saņemtu uznirstošajā logā datumu ar tekošu.
10) Uzzināt, kā rādīt skatam piesaistītā objekta laukus ar kādu nosacījumu vai formatēšanu (converters), un saģenerēt atbilstošo kodu.
11) Uzzināt, kā atvērt lapu virs TabBar.
12) Uzzināt, kā sarakstu no enum vērtībām attēlot checkboxos, un saģenerēt atbilstošo kodu.
13) Saprast, kādos gadījumos labāk atvērt jaunu lapu ar GoToAsync, padodot objektu vārdnicā ar QueryProperty un On...Changed.
14) Uzlabot lapas dizaina kvalitāti atsevišķos failos (norādīts ar komentāriem šajos failos).
15) Saprast, kas ir Auto un * XAMLā.
16) Uzzināt, kā paziņot UI, ka izmainījās pogas teksts.
17) Uzzināt, kur pievienot try-catch bloku, lai MAUI lietotne rādītu kļūdu paziņojumus.
18) Apdomāt, kā nosaukt API ceļus.
19) Uzzināt, ka HTTP metodē DELETE jāpadod identifikators, nevis viss objekts.
20) Uzzināt, kā atgriezt Task no sinhronās metodes.
21) Pajautāt, kur likt ToDto/ToDomain mapperus un kā tie izskatīsies.
22) Pajautāt, ko darīt ar CreateHabitDto, MarkHabitAsCompletedDto un UpdateHabitDto.

3) Paskatīties, kā izskatās API endpointi.
