Projekta izstrādes laikā tika izmantots:

- MI rīks Gemini šādām vajadzībām:

1) Uzzināt, kā ir pieņemts nosaukt projektus .NET risinājumā.
2) Uzlabot koda kvalitāti atsevišķos failos (norādīts ar komentāriem šajos failos).
3) Uzzināt, kā strādā DTO, kāpēc tie ir vajadzīgi un kā tos implementē C#.
4) Uzzināt, kā padod JSON serializātoram divus sarakstus uzreiz.
5) Saprast, ka JSON serializācijai vajadzīgs konstruktors, kur visu parametru tipi un nosaukumi sakrīt ar publisku īpašību tipiem un nosaukumiem klasē.
6) Uzzināt, kā viewmodeļos iegūt lietotāja ID.

- kursa GitHub repozitorijs "UzdevumuParvaldnieks" šādām vajadzībām:

1) Paskatīties, kā lasīt/rakstīt failā.
2) Paskatīties, kāda ir MAUI lietotnes failu struktūra un saturs.
